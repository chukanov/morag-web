# Стек и деплой

## Локально: движок в docker compose

```bash
export MORAG_REPO=../../morag            # чекаут движка (код монтируется из рабочего дерева)
SPACE=../corpora/<семья>/spaces/<слаг> docker compose -f deploy/docker-compose.yml up -d qdrant embedder-gte pipelines pipelines-record
SPACE=… docker compose -f deploy/docker-compose.yml --profile tools run --rm indexer index
```

`SPACE` — каталог пространства (в нём `morag-config.yml`, `records/`, `engine-state/`),
`PIPELINE` — имя модели (равно `engines.<слаг>.model` в `app/config.yml` сайта и
`PIPELINE_NAME` контейнера), `NO_PROXY_EXTRA` — ваш LLM-шлюз, к которому контейнеры ходят мимо
прокси. Два процесса на одном индексе: `pipelines` (весь корпус) и `pipelines-record` (вопрос к
одной записи — свой промпт без карты и каталога); один процесс морага обслуживает один конфиг.

Пример конфига движка — `corpora/example/morag-config.example.yml` (и `-record`): рабочий
`morag-config.yml` с ключом лежит рядом и в git не идёт. Правим ПРИМЕР и пересобираем рабочий,
иначе структура двух файлов разъезжается молча. Промпт агента живёт в конфиге, не в коде —
`agent-prompt.md`.

## ⚠️ Индексация — опасная операция

1. **Индексатор удаляет всё, чего нет в источнике.** Это не «добавить документы», а полная
   синхронизация: `orphaned = stored − current → cascade_delete`. Подсунуть каталог с одной новой
   записью — снести корпус (проверено на живом проде: осталось 39 чанков из 2380). Источник
   при индексации всегда полный; `sources[].path` указывает на `records/`, не на корень корпуса.
2. **«Изменился ли документ» решается по mtime.** `make_record.py` пишет файл, только если
   содержимое изменилось; rsync-доставка меняет mtime — первый прогон после переезда
   переиндексирует всё, ровно один раз.
3. **Счётчик прогонов не восстанавливается из базы:** перед прогоном класть в
   `MORAG_RUN_COUNTER_FILE` максимум из базы, иначе дубли со старым текстом.
4. **`indexing.concurrency: 1`:** sparse-эмбеддер — торч на CPU, при 3 cgroup убивал контейнер.
5. **Падение эмбеддера выглядит как отказ индексатора** (`ConnectError`, «0 indexed, N skipped»);
   причина видна со стороны машины (`dmesg | grep oom-kill`, `docker inspect … RestartCount`).
6. **Перед индексацией — снапшот** (`POST /collections/{c}/snapshots`): автоснапшотов нет.
7. **Смена dense-эмбеддера = полная переиндексация:** отпечаток `sha256(model|dim|base_url)`,
   даже слэш в конце адреса — другой индекс. Переезд той же модели на другой адрес —
   `rebind-embedder` в мораге, без пересчёта векторов.
8. **Карту знаний мерить после каждого `rebuild-km`** (`system prompt N tok` в логе): раздутая
   карта незаметно съедает окно модели.

Правка промпта справок к чанкам (`indexing.context.prompt`) — тоже переиндексация: справка
входит в dense-вектор. Остальные секции промпта подхватываются по mtime, без рестарта.

## Сайт

```bash
pip install -r app/requirements.txt
MORAG_WEB_CONFIG=/путь/к/корпусу/app/config.yml python3 -m uvicorn app.main:app --host 127.0.0.1 --port 8080
```

Конфиг корпуса может лежать в репозитории корпуса: относительные пути в нём считаются от него
самого. Данные BFF (`app/data`: журнал, лимиты, ключ cookie, снимки учёток) — там, куда указывает
конфиг; по умолчанию у примера — рядом с кодом, у корпуса стоит назвать `./data/…` явно, чтобы
данные не оказались в каталоге кода под `rsync --delete`.

## Загрузка записей через сайт

Пока нет сервера с моделями, докладчик транскрибирует у себя и загружает пакет (`docs/upload.md`):
на сервере — блок `upload` в `app/config.yml` (`enabled`, `archive` = корень архива видео,
`index` = команда индексации; у compose — `… --profile tools run --rm indexer index`). Стейджинг
`<семья>/incoming` — вне `records/`; принятые записи живут на сервере, и репозиторий корпуса
обязан забирать их оттуда до своей доставки с `--delete`.

## Сервер за обратным прокси

Шаблоны — `deploy/server/site.service.example` (systemd: `WorkingDirectory` — корень чекаута,
иначе `app/logging.py` затеняет стандартный `logging`; `MORAG_WEB_CONFIG` — конфиг корпуса) и
`deploy/server/apache.conf.example` (проксировать префиксы поимённо, SSE `/api/ask` без gzip и с
таймаутом в минуты). За прокси в `app/config.yml` — `server.trusted_proxy_hops: 1`: лимиты и
журнал берут IP из `X-Forwarded-For`, cookie получает `Secure` по `X-Forwarded-Proto`; без
этого все посетители — один loopback. Пароля на прокси нет — вход держит сайт (`auth.md`).

Видео сайт не раздаёт в проде: плеер тянет файл прямо из архива (`media_base` в конфиге) —
архив обязан отвечать `Accept-Ranges: bytes` и `206` на диапазон, иначе перемотка и караоке не
работают. `crossorigin` на `<video>` не ставить.

## Транскрибация (кратко)

Стек — `morag/services/asr-adaptor/deploy/mac/` (whisper, pyannote, CAM++, LLM-стадии); профиль
корпуса — `asr-profile.env` (в git, без секретов), машинные адреса и ключи — `~/.asr-stack.env`
(0600). Ноутбук — эталон, вторая машина — только исполнение: правка едет в git, реестр голосов
ездит с прогоном и не размножается (биометрия, вне git всегда), версии зависимостей прибиты,
каждая расшифровка несёт отпечаток установки (`x_enriched.env`). Обёртка — `corpora/example/transcribe.sh`.
