# Своя запись — на сайт: транскрибация у себя, сборка на сервере

Режим для установки **без сервера с моделями**: у сайта есть только BFF и движок поиска, а
транскрибация (диаризация, whisper, LLM-стадии) и экран из видео (Vision) идут на ноутбуке того,
кто загружает запись, — на Mac с Apple Silicon, через его собственный ключ к LLM-шлюзу. Сервер
получает пакет и доводит его до записи тем же путём, что и запись владельца корпуса.

```
Mac докладчика                                  сервер сайта
─────────────────────────────────────────       ──────────────────────────────────────
видео ─► ffmpeg ─► стек morag (asr-adaptor)     /api/ingest: манифест, файлы, finish
         └─► artifact.json (речь, слова)    ─►  incoming/<id>/ (стейджинг, вне records/)
видео ─► slides_from_video, intro_frame,          ├─ Speaker_N → Speaker_100000+N
         describe_slides (Vision),                ├─ видео → архив (media: Uploads/<id>.mp4)
         screen_refs, make_annotations       ─►   ├─ make_record с настоящими словарями и раскладкой
         └─► record.{slides,refs,annotations}     ├─ сайдкары экрана, кадры, слайды → records/…/<id>/
             + slides.zip                         ├─ after: обложка, снимок голосов
                                                  └─ index: индексатор (справки, BM25, карта)
```

## Установка (один раз, Mac на Apple Silicon)

Два пути, и они для разных людей.

**С сайта — тому, кто просто хочет выложить запись.** Сайт раздаёт готовое зеркало (см.
«Раздача с сайта» ниже): страница `/ingest` даёт файл для двойного щелчка и строку

```bash
curl -fsSL https://site.example.org/api/ingest/get/<пропуск>/install | sh
```

Она ставит всё в `~/morag-ingest`: портативный python 3.12 (распаковкой, не установкой),
статический ffmpeg, снимок инструментов и движка, модели и приложение
`~/Applications/Загрузить запись.app`. **Ни Homebrew, ни прав администратора, ни учётки на
Hugging Face** — модели приезжают с сайта. Ключ к шлюзу человек вписывает в самом приложении.

**Из репозитория — тому, кто платформу дорабатывает:**

```bash
git clone https://github.com/catonmoon/morag-web && cd morag-web
./tools/ingest-install.sh          # brew: ffmpeg, python; чекаут morag рядом; стек; модели; video-venv
export PATH="$HOME/asr-stack/bin:$PATH"
morag-ingest login --site https://site.example.org
```

Здесь модели качаются с Hugging Face: whisper и CAM++ публичные, **pyannote** — под вашим
токеном, после принятия условий на странице модели. Установщик спрашивает адрес LLM-шлюза,
модель, ключ и токен и пишет их в `~/.asr-stack.env` (0600).

В обоих случаях наминг голосов выключен (`ASR_ENABLE_NAMING=0`): имена ставят на сайте.

## Загрузка: окно приложения

`morag-ingest app` (или ярлык, который делает установщик) открывает **окно**: перетащите в него
видео — название подставится из имени файла, дата из даты файла, остальное скрыто под
«подробнее». Дальше полоса прогресса по шагам (звук → расшифровка → экран → загрузка → сервер) и
карточка с ссылкой на готовую запись. Ключ к LLM-шлюзу вводится там же, в «настройках»: он
пишется в файл стека (0600), а поднятый стек гасится, чтобы адаптер перечитал ключ.

Окно — `WKWebView` в нативном окне (PyObjC, `tools/requirements-app.txt`), внутри та же страница,
что и в браузере. ⚠️ Перетаскивание перехватывает наш подкласс `WKWebView`: иначе WebKit
открыл бы брошенный файл вместо страницы. Нет PyObjC (не мак) — `app` открывает браузер.

⚠️ Окно живёт, пока жив процесс: закрытие во время работы спрашивает подтверждение. Свернуть —
можно, закрыть — прервать расшифровку.

## Загрузка: страница в браузере

`morag-ingest ui` — то же самое, но страницей в браузере (это локальный сервер на `127.0.0.1`,
наружу он не смотрит; адрес с токеном печатается в терминале). Годится там, где окна нет.
Перетащить файл в браузер тоже можно: пути браузер не даёт, поэтому файл ищется по имени и
размеру среди Загрузок, Рабочего стола и Movies — не нашёлся, выбирается из списка.

⚠️ Видео **не загружается в браузер** — конвейер читает файл с диска; копировать гигабайты
через localhost незачем. ⚠️ Страница требует токен из адреса и отвергает чужой `Origin`: петля
сама по себе не защищает от вкладки постороннего сайта, открытой в том же браузере.

## Загрузка: командная строка

Та же работа без страницы:

```bash
morag-ingest run talk.mp4 --title "Kafka без боли" --date 2026-03-12 \
    --event "Доклады" --speakers "Мария Кузнецова" --summary "О чём" --slides deck.pdf --stack
```

`--stack` поднимает стек транскрибации перед работой и гасит после (иначе — `stack.sh up`
руками). `--event` — из списка сайта (`morag-ingest options`): рубрика решает ветку и место
записи по правилам раскладки корпуса; без правил — любая. `--speakers` попадают в шапку
докладчиками, если у ветки модель `talk`. `--no-screen` — без экрана из видео (втрое быстрее,
но поиск не увидит слайды). Сколько ждать на M-серии: час записи ≈ 10–15 минут транскрибации,
~5 минут экрана, загрузка видео — по сети; на сервере сборка секунды, индексация — до 20 минут
(справка LLM к каждому чанку плюс BM25 и карта по всему корпусу).

Каждый шаг возобновляем: упало — запустите ту же команду, продолжится с упавшего
(`~/morag-ingest/<id>/state.json`; артефакт и экран не пересчитываются, отданные файлы не
льются заново). `morag-ingest status <id>` — что с записью на сервере.

## Что получится и чего не будет

- Запись на сайте: расшифровка с караоке, видео из архива, экран в поиске (если снят), докладчики
  из `--speakers`, аннотация из `--summary`. Адрес печатает `run`.
- **Голоса приезжают безымянными** (`Speaker_N`) — у вашей машины свой реестр голосов, и
  сервер сдвигает номера в отдельный диапазон (`Speaker_100000+`), чтобы они не пересеклись с
  корпусными. Назвать: «Это я» у своего голоса в режиме правки, остальных — админ карточкой
  голоса. Сквозное узнавание голосов между записями — когда появится центральный сервер.
- Категория, темы и — если названия не дали — заголовок появляются САМИ, до индексации
  (`ingest.enrich`, `tools/auto_meta.py`): их ставит сервер ключом корпуса. Выключено — как
  раньше, плановой разметкой.
- Сырой артефакт едет на сервер и лежит в записи (`record.json`) — правка реплик на сайте работает.

## Раздача с сайта: зеркало, пропуск, страница

Чтобы установка не требовала ни brew, ни учёток, сайт раздаёт **зеркало** — каталог
`ingest.dist_dir` рядом с корпусом: портативный python (`python-build-standalone`), статический
ffmpeg (из колеса `imageio-ffmpeg`), снимок `tools/`, снимок движка транскрибации, модели
(whisper, CAM++, pyannote, MMS_FA) и настройки корпуса. Содержимое готовит владелец корпуса
своим инструментом (у нас — `build_dist.py` в приватном репозитории) и кладёт рядом с сайтом;
опись — `manifest.json` (её читает страница) и `manifest.sh` (её читает установщик: на чистом
маке нечем разобрать JSON, системный `python3` там — заглушка Xcode).

Ручки (`app/api/ingest.py`, `app/content/dist.py`):

| ручка | кому | зачем |
|---|---|---|
| `GET /api/ingest/dist` | вошедшему с правом `ingest` | что лежит на зеркале, строка установки, пропуск |
| `GET /api/ingest/app.zip` | ему же | zip с `.command` — путь «двойным щелчком» |
| `GET /api/ingest/get/<пропуск>/install` | кому угодно с пропуском | `tools/install-mac.sh` с подставленными адресом и пропуском |
| `GET /api/ingest/get/<пропуск>/file/<имя>` | ему же | файл зеркала, с `Range` |

⚠️ **Пропуск вместо сессии.** Ставится всё строкой в терминале, а у `curl` cookie сайта нет и
быть не должно: сессия сотрудника в истории shell — плохая идея. Пропуск подписан ключом,
ВЫВЕДЕННЫМ из ключа сессий (`AuthService.derived_secret`), живёт неделю и даёт ровно одно право
— брать файлы этого каталога. Поэтому и только поэтому `/api/ingest/get/…` открыт на рубеже
входа (`PUBLIC_PREFIX`), а `/api/ingest/dist` и `app.zip` — нет.

⚠️ **Gatekeeper.** Карантин вешает тот, кто СКАЧАЛ файл, поэтому приложение, собранное
установщиком на месте, не проверяется вовсе — ни «неизвестного разработчика», ни походов в
настройки. Скачанный zip помечен: первый запуск `.command` — правый щелчок → «Открыть»
(проверено: Chrome ставит `com.apple.quarantine`, Finder распаковывает с битом запуска и
меткой). Строка `curl … | sh` не помечает ничего. Ad-hoc-подпись (`codesign -s -`) карантин не
снимает — она нужна, чтобы macOS не считала приложение новым после каждого обновления и не
спрашивала доступ к папкам заново.

⚠️ **`ffprobe` в зеркале нет** — статической сборки под arm64 нет ни в одном колесе PyPI.
Свойства видео там читает `av` (PyAV), см. `slides_from_video.probe`; где `ffprobe` стоит,
поведение прежнее.

Страница `/ingest` (пункт «Загрузить свою запись» в меню пользователя, виден по праву `ingest`)
показывает обе дороги, размер, сколько ждать и срок жизни ссылки. Зеркала нет — страница
честно говорит об этом, а не показывает пустоту.

## Сервер: что включить

`app/config.yml` корпуса, блок `ingest` (см. `app/config.example.yml`): `enabled: true`,
`archive` — корень архива видео, тот же, что раздаёт `media_base`; `video_dir` — подкаталог под
загрузки; `build` — `make_record` из venv сайта; `after` — обложка и снимок голосов; `index` —
команда индексации (у docker-compose — `indexer … index`); `min_free_gb` — сколько места
оставлять; `enrich: true` — доразметка принятой записи; `dist_dir` — каталог зеркала для
раздачи приложения. Право `ingest` — любой вошедший (`app/auth/roles.py`); без входа — только петля.
Стейджинг `<семья>/incoming` — вне `records/`, индексатор его не видит; в git корпуса и в
доставку он не входит. ⚠️ Если корпус живёт в git на другой машине, записи, принятые сервером,
надо забирать ОТТУДА (у нас — `deploy_server.py pull-records` перед `push`), иначе следующая
доставка с `--delete` их снесёт.

Обратный прокси: тело PUT идёт потоком, лимита на размер у BFF нет (кроме `max_gb`); у apache
2.4 `LimitRequestBody` по умолчанию без лимита, таймаут чтения — на минуты, как у `/api/ask`.
