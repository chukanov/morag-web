# BFF + фронт

Тонкий backend-for-frontend: проксирует SSE от morag pipelines в наш контракт,
отдаёт бренд/тему/записи из `corpora/<name>/` и ведёт приватный журнал.
Из мораги ничего не импортируем — только HTTP.

## Запуск (разработка)

```bash
pip install -r app/requirements.txt
python3 -m uvicorn app.main:app --reload      # → http://127.0.0.1:8080
```

Отдаёт и API, и статику фронта с одного порта — так нет CORS и открывается
как обычный сайт. ES-модули по `file://` не работают, поэтому просто открыть
`web/index.html` в браузере нельзя: нужен этот сервер.

Нужен живой движок: `pipelines` на `127.0.0.1:9099` (плюс qdrant и GTE рядом).

## Конфиги

| Файл | Что | В git |
|---|---|---|
| `app/config.example.yml` | дефолты, плейсхолдеры | да |
| `app/config.yml` | рабочий: ключ движка, egress-прокси, лимиты | **нет** |
| `corpora/<name>/site.yml` | slug, бренд, тема, **разделы списка** (`content.sections`) | да |

**Лимиты** (`limits.rate_limit`) защищают кошелёк, а не сервер: каждый вопрос — платный агентский
цикл. Ведро на адрес (5 сразу, +1 в 2 минуты), один активный вопрос с адреса и дневной потолок на
весь сайт (500). Стоят только на `/api/ask`. Снимаются целиком — `enabled: false`, по одному рубежу —
нулём в поле. Отказ: `429` + `Retry-After`. Дневной расход виден в `/api/health` (`asked_today`).

**Вход** (`auth`, 16.09) — форма `/signin` и cookie в самом BFF, а не пароль на прокси (прокси-
помощники в браузерах коллег ловят 401-челлендж). Провайдеры: каталог AD (`auth.ldap`: человек
связывается своей учёткой по `bind_template`, сервисной нет) и локальные пользователи
(`auth.users`, хэш — `tools/auth_password.py`).
Роли `viewer < editor < admin` (`auth.roles`: по логину, по группе каталога, умолчание): реплики
правит `editor`, имена голосов и «починить везде» — `admin`; «это я» у безымянного голоса — любой
вошедший. `auth.access.groups` — маски групп каталога, без которых доменному пользователю сайт
закрыт (403 с `access.message`); локальные проходят всегда. Выключено (`enabled: false`,
умолчание) — сайт анонимный, как раньше. Снимки учёток и ключ cookie — `app/data/auth/`.
Разбор — CLAUDE.md, «Авторизация».

Любое поле переопределяется окружением с префиксом `MORAG_WEB_`:
`MORAG_WEB_ENGINE__API_KEY`, `MORAG_WEB_JOURNAL__IP_SALT`,
`MORAG_WEB_SERVER__WEB_ROOT` (двойное подчёркивание = вложенность).

Прод — `docs/deploy.md` (обратный прокси, BFF службой systemd): рабочий `app/config.yml` живёт у
корпуса (0600) с `server.trusted_proxy_hops: 1` — сайт за обратным прокси, без этого
X-Forwarded-For разберётся неверно, все посетители станут одним адресом, а cookie не получит
`Secure`.

## Эндпоинты

| Метод | Путь | Зачем |
|---|---|---|
| GET | `/api/health` | живость, число записей, свободные слоты |
| GET | `/api/site` | бренд и токены темы (явный allowlist, без ключей) |
| GET | `/api/records` | **дерево разделов**: раздел → подраздел → записи |
| GET | `/api/records/{id}/transcript.md` | скачать расшифровку |
| GET | `/api/records/{id}/words` | слова с временами: вся запись либо `?start=&end=` — кусок под карточку |
| GET | `/api/records/{id}/slides.pdf` | слайды доклада инлайн |
| GET | `/api/media/{имя}` | видео (только для разработки; в проде видео раздаёт архив сервера, `media_base`) |
| GET | `/api/brand/{файл}` | картинки бренда из каталога корпуса |
| POST | `/api/ask` | вопрос → SSE-поток кадров |
| POST | `/api/feedback` | 👍/👎 к ответу по `answer_id` |
| GET | `/api/auth/state` | открыто: включён ли вход, провайдеры, название для формы, вошёл ли уже |
| POST | `/api/auth/login` | открыто: `{login, password}` → cookie сессии + `me`; 401 одним текстом, 429 лимит, 503 каталог недоступен |
| POST | `/api/auth/logout` | снять cookie |
| GET | `/api/auth/me` | кто вошёл: логин, имя, роль, должность, отдел, `can: {edit, voices}` (без входа — пустая личность с теми же флагами) |
| GET | `/api/auth/me/photo` | фото из каталога, если есть |
| POST | `/api/voices/{voice}` | имя голоса — `admin` |
| POST/DELETE | `/api/records/{id}/edits` | правки реплик — `editor` |
| POST | `/api/fixes` | «починить везде» — `admin` |

Без сессии при включённом входе: `/api/*` → 401 `{"detail": "нужен вход"}` (без `WWW-Authenticate`),
страницы → 302 на `/signin?next=…`; открыты форма, `/api/auth/state|login`, `/api/health` и статика.

Поток `/api/ask`: `answer_id` → `status`* → `token`* → `citation`* → `done`
(или `error`). Кадры цитат несут `rec` и `sec` — по ним фронт делает ссылку
на запись с нужной секунды.

ⓘ Ответ `/api/records` — дерево одной формы на каждом узле: `group`, `count`, `records`,
`children`. Раздел с осью второго уровня держит записи в детях, без оси — прямо в `records`.
Обходить его надо хелпером `flattenRecords()` из `web/js/api.js`, а не вручную.

## Тесты

```bash
python3 -m pytest -q          # 302 теста, офлайн, без трат на LLM
for f in tests/js/*.mjs; do node "$f"; done   # 11 раннеров рендера, без браузера
```

Ключевой — `tests/test_engine.py`: гоняет записанные SSE-фикстуры, разрезая
поток по разным смещениям. Ловит границы чанков, кириллицу между чанками и
главную граблю движка: `data: [DONE]` приходит **без** завершающих `\n\n`.

Перезаписать фикстуры (единственное, что стоит денег — пара вызовов LLM):

```bash
curl -N -s -X POST http://127.0.0.1:9099/v1/chat/completions \
  -H 'Authorization: Bearer 0p3n-w3bu!' -H 'Content-Type: application/json' \
  -d '{"model":"morag-audio","stream":true,"messages":[{"role":"user","content":"Что говорили про видеокарту H200?"}]}' \
  > tests/fixtures/engine_h200.sse
```

Расширение — `.sse`, не `.jsonl`: правило `*.jsonl` в `.gitignore` иначе молча
съест фикстуры.

## Структура

```
app/
  api/       эндпоинты (единственный слой, знающий про Request/Response)
  auth/      вход: роли, локальные пользователи, каталог, cookie, снимки учёток, gate
  engine/    SSE-парсер, нормализатор кадров, HTTP-клиент к мораге
  content/   индекс записей и расшифровки (читаем только .md, не .json)
  chat/      сборка промпта, включая контекст чтения
web/
  css/       tokens.css — тема корпуса, app.css — общая вёрстка
  js/        ES-модули без сборки
```
