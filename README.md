# morag-web

Сайт для записей встреч, докладов и учебных курсов: расшифровка с караоке по словам, вопрос к
корпусу и к одной записи с ответом по секундам видео, правка расшифровок из браузера, вход
своей доменной учёткой. Веб-морда к движку [morag](https://github.com/catonmoon/morag): движок
транскрибирует, индексирует и отвечает, этот репозиторий показывает и спрашивает.

Одна платформа — много корпусов. Всё, чем сайты отличаются друг от друга (название, знак,
цвета, разделы, кнопки, промпт агента), живёт в конфиге корпуса, а корпус живёт в своём
репозитории. Здесь — только код, синтетический демо-корпус и шаблоны.

## Из чего состоит

```
видео/звук ─▶ morag / services/asr-adaptor  (whisper, диаризация, реестр голосов, LLM-правки)
                    ▼  сайдкар <имя>.json (слова с временами, голоса)
       tools/make_record.py  ─▶  records/<ветка>/<год>/<id>/record.md + record.words.json
       tools/slides_from_video.py … make_annotations.py  ─▶  экран из видео (record.annotations.json)
                    ▼
       morag indexer (cli/main.py)  ─▶  Qdrant
                    ▼
       morag pipelines (агент, ретрив)  ◀─HTTP─▶  app/ (BFF, FastAPI)  ◀─▶  web/ (фронт, ES-модули)
```

| каталог | что |
|---|---|
| `app/` | BFF: конфиг слоями, индекс записей, вход и роли, разрешение цитат в секунды видео, прокси к движку |
| `web/` | фронт без сборки: список, читалка с караоке, чат, календарь, верстак голосов, форма входа |
| `tools/` | сборка записи из сайдкара адаптера, экран из видео, словари правок, снимок голосов, классификатор, пробник вопросов |
| `corpora/demo/` | три синтетические записи — на них идут тесты и поднимается сайт без чужого корпуса |
| `corpora/example/` | шаблоны конфигов корпуса: витрина, пространство, движок, профиль транскрибации, таксономия, пробы |
| `deploy/` | поисковый стек в docker compose и шаблоны для сервера |
| `docs/` | формат записи, раскладка корпуса, вход, экран из видео, промпт агента, деплой; `frontend.md` — решения и грабли интерфейса |

## Быстрый старт на демо

```bash
pip install -r app/requirements.txt
python3 -m uvicorn app.main:app --port 8080      # http://127.0.0.1:8080 → демо-корпус
python3 -m pytest tests/ -q                      # ~360 тестов на демо
for f in tests/js/*.mjs; do node "$f"; done     # логика фронта без браузера
```

Без движка сайт показывает записи и караоке; вопросы к агенту требуют поднятого стека
(`deploy/docker-compose.yml`) и адреса в `app/config.yml`.

## Повторить на своих записях

1. **Корпус — отдельный каталог (лучше — репозиторий).** Скопируйте `corpora/example/` как
   каркас: `hub.yml` (витрина, правила раскладки, роли) или один `site.yml` (одно пространство),
   `morag-config.yml` для движка, `asr-profile.env`, `taxonomy.yml`, `ops.env`. Что означают
   поля — `docs/corpus-layout.md`.
2. **Транскрибация** — стек morag на своей машине (`morag/services/asr-adaptor/deploy/mac/`),
   профиль корпуса — `asr-profile.env`, обёртка — `transcribe.sh` из шаблонов. Результат —
   сайдкар `<имя>.json` рядом со звуком.
3. **Сборка записи** — `python3 tools/make_record.py <сайдкар> --title … --date … --event …`:
   получаете `record.md` (шапка + реплики с тайм-кодами), `record.words.json` (слова с
   временами), словари правок применяются при сборке. Формат — `docs/record-format.md`.
4. **Экран из видео** (по желанию) — `slides_from_video.py → describe_slides.py → screen_refs.py
   → make_annotations.py`: слайды и обращения «вот здесь» уезжают в чанки рядом с речью.
   `docs/screen-layer.md`.
5. **Индексация и ответы** — `deploy/docker-compose.yml`; ⚠️ индексация синхронизирует
   источник целиком, читайте `docs/deploy.md` до первого запуска.
6. **Сайт** — `app/config.yml` (по образцу `app/config.example.yml`): каталог корпуса, адреса
   движков, вход. Пути в конфиге считаются от файла конфига, поэтому он может лежать в
   репозитории корпуса: `MORAG_WEB_CONFIG=/путь/к/config.yml python3 -m uvicorn app.main:app`.

## Вход и роли

Форма `/signin` и cookie в самом BFF — без 401-челленджа (его ломают прокси-помощники в
браузерах). Провайдеры: каталог AD/LDAP **своей учёткой** (bind по шаблону `{login}@домен`,
сервисной учётки не нужно) и локальные пользователи со scrypt-хэшем. Роли `viewer < editor <
admin` по логину и группе; доступ к сайту можно ограничить маской группы. `docs/auth.md`.

## Что здесь по-другому

- **Запись — это каталог**, раздел сайта — каталог на диске (`records/<ветка>/<второй
  уровень>/<id>/`): один источник правды и для движка, и для списка.
- **Абзац расшифровки — тайм-код**, а не оформление: реплика режется по концу предложения с
  мереным временем, чтобы клик по цитате открывал нужную секунду, а не «примерно там».
- **Правки — в словари, не в файлы:** имена голосов, гарблы и поместные правки реплик
  применяются при пересборке; убранная строка словаря отменяет правку.
- **Экран и речь — в одном чанке:** агент видит слайд того момента, о котором говорят.
- **Доменного в коде нет** — это проверяется тестом, а корпус в git этого репозитория не
  попадает по построению. Если репозиторий корпуса лежит рядом и держит свой сторож
  (`tools/leak_check.py --web`), хук `deploy/git-hooks/pre-push` зовёт его перед каждым push:
  `git config core.hooksPath deploy/git-hooks`.
